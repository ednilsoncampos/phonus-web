Leia este documento  docs/integracao-web-recibo.md para adicionar a funcionalidade de compartilhar recibo.

Para o web e o app, o essencial é:
- Baixar: GET /lancamentos/{id}/recibo?formato=pdf|png devolve o arquivo (binário, não JSON). Tem que ser fetch com o token e blob. Um <a href> não leva o Authorization.
- Botão de recibo: só em lançamentos de venda. Compra devolve 422.
- Compartilhar: navigator.share com o arquivo, ou baixar como alternativa. A API só entrega o arquivo; o compartilhamento é do cliente.
- Limite: 30 recibos por minuto por usuário (erro 429, com Retry-After). Baixe uma vez e reutilize o arquivo.
- Empresa: GET /empresa e PUT /empresa; o PUT é só do ROOT, e a tela de edição deve aparecer só se permissoes tiver EMPRESA_GERENCIAR.
